# Petal Bloom Journal

Live Website: https://petal-bloom-journal.base44.app

## How to run
1. Double-click install.bat
2. Double-click run.bat
3. Open http://localhost:5173

## Files
- install.bat = installs libraries and plug-in
- run.bat = runs the app
- install_log.txt = install log
- run_log.txt = run / exe log
